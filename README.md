# ShowRoom-3D

Interactive, lightweight 3D web showrooms empowering artisans to showcase and sell spatial craft directly via WebGL and WhatsApp.

## Run locally

This first interface is dependency-free so it can be previewed without a Node.js installation. Open `index.html` in a browser, then use the collection and product links to move through the showroom.

Routes are represented as static pages:

- `/index.html` - landing page
- `/v/vertex-crafts/index.html` - Vertex Crafts storefront
- `/p/sr-042/index.html` - interactive Axis Dining Table view

The product view includes finish selection, live price changes, drag rotation, zoom controls, and a WhatsApp order link.
